# Tree ID · 树木识别

[![Website](https://img.shields.io/badge/Website-ychenzgithub.github.io%2FTreeID-2f6b3a?style=for-the-badge)](https://ychenzgithub.github.io/TreeID/)

**🌐 <https://ychenzgithub.github.io/TreeID/>**

A photo guide for learning to identify trees. It opens in English, and a 中文 button switches the interface and tree names to Chinese.

一个树木识别图鉴网站：从整体、叶、花、果、树皮认识常见树木，并整理了 Science Olympiad Forest Finds 树种、检索表、易混树种对比和针叶树分类。默认英文，可一键切换中文。

## What's inside

| Section | Content |
| :--- | :--- |
| Photo atlas · 常见树图鉴 | 92 common trees, each shown as whole tree, cartoon, leaf, flower, fruit and bark (548 photos). Search in English or Chinese, jump by letter, or show one part across all trees. |
| Science Olympiad · Forest Finds | The 33 Division A species with appearance, location, uses, ID video and photos. Includes identification-key filters (leaf shape, arrangement, cones and fruits) and 10 look-alike comparison figures. |
| 2004 National Tournament list | Notes on 26 Forestry species, 10 of them with photos, plus a link to the full list. |
| Conifers · 针叶树 | Classification from Pinophyta down to genus and species, linked to atlas photos and Science Olympiad species. |
| Botany basics · 植物学基础 | 13 reference figures: leaf shapes and margins, compound leaves, and the parts of a leaf, twig, flower and trunk. |
| Tips, maps, tools | MADCap Horse (trees with opposite branching), city tree maps, ID apps and webpages. |

## Files

- `index.html`, `assets/css/style.css`, `assets/js/app.js`: the page (static; no build step).
- `assets/js/data.js`: tree and species data.
- `assets/js/content.js`: links, tips, the conifer classification and Chinese labels.
- `assets/img/`: photos and figures (WebP).

## Image note

The photos were collected from many websites for personal study. Where the original page or file name is known, it is shown when you enlarge a picture.
