# Tree ID · 树木识别

[![Website](https://img.shields.io/badge/Website-ychenzgithub.github.io%2FTreeID-2f6b3a?style=for-the-badge)](https://ychenzgithub.github.io/TreeID/)

**🌐 <https://ychenzgithub.github.io/TreeID/>**

A photo guide for learning to identify trees. It opens in English, and a 中文 button switches the interface and tree names to Chinese.

一个树木识别图鉴网站：从整体、叶、花、果、树皮认识常见树木，并整理了 SciOly Forest Finds 树种、检索表、易混树种对比、植物学基础和针叶树分类。默认英文，可一键切换中文。

## What's inside

| Section | Content |
| :--- | :--- |
| Photo atlas · 常见树图鉴 | 92 common trees, each shown as whole tree, cartoon, leaf, flower, fruit and bark (548 photos). Search in English or Chinese, jump by letter, or show one part across all trees. |
| SciOly Forest Finds | The 33 Science Olympiad Division A species with appearance, location, uses, ID video and photos. Includes identification-key filters (leaf shape, arrangement, cones and fruits), 10 look-alike comparison figures, and notes on 26 more forestry species. |
| Botany basics · 植物学基础 | 13 reference figures (leaf shapes and margins, compound leaves, parts of a leaf, twig, flower and trunk), the MADCap Horse mnemonic for trees with opposite branching, and the conifer classification from Pinophyta down to genus and species. |
| Maps & tools · 地图与工具 | City tree maps, tree ID apps and an urban tree species directory. |

## Files

- `index.html`, `assets/css/style.css`, `assets/js/app.js`: the page (static; no build step).
- `assets/js/data.js`: tree and species data.
- `assets/js/content.js`: links, the MADCap Horse mnemonic, the conifer classification and Chinese labels.
- `assets/img/`: photos and figures (WebP).

## Image note

The photos were collected from many websites for personal study. Where the original page or file name is known, it is shown when you enlarge a picture.
